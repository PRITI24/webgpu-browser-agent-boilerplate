# ⚡ webgpu-browser-agent-boilerplate

[![WebGPU](https://img.shields.io/badge/WebGPU-W3C-blue)](https://www.w3.org/TR/webgpu/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0+-3178C6?logo=typescript)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

A minimal, beginner-friendly **TypeScript** starter kit demonstrating how to check **W3C WebGPU (`navigator.gpu`)** availability and run a basic WGSL compute shader in modern Chromium-based browsers.

---

## 📂 Project Structure

- `src/webgpu_compute.ts` — Checks `navigator.gpu` adapter support and defines a minimal WGSL vector addition compute shader.
